Privacy Policy

Last updated: October 2026

Jarvis is a personal voice assistant built and operated by a single individual, for that individual's own use. It is not a public service, has no user accounts or sign-up, and no one other than its owner authorizes or uses it.

What data this app accesses

With the owner's own Google account authorization, Jarvis accesses:

  • Google Calendar events (to read upcoming events and create new ones at the owner's request)
  • Gmail messages (to read recent email metadata and content, and to create draft replies — Jarvis never sends email on its own)

How this data is used

Calendar and email data is used only to answer the owner's own questions and carry out the owner's own requests (e.g. "what's on my calendar," "draft a reply to this email"). It is fetched live when needed and is not resold, shared with advertisers, or used to build any profile beyond operating the assistant for its one user.

Who else processes this data

To generate responses, some of this data is sent to:

  • Anthropic's Claude API, which powers the assistant's conversation and decision-making
  • A fast, free-tier LLM routing service (one of several interchangeable providers such as Groq, Cerebras, or Google's Gemini API), used only for lightweight tasks like judging whether a given email is worth mentioning in a quick summary

No other third parties receive this data. It is never sold.

Where data is stored

Any durable data this app keeps (e.g. reminders, short notes it has learned from conversation) is stored locally on the owner's own devices, not on any shared or public server.

Revoking access

The owner can revoke this app's access to their Google account at any time via Google Account → Security → Third-party access.

Contact

This is a personal project with a single owner/operator and no separate support channel.
